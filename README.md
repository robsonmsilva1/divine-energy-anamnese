# Divine Energy · Anamnese

Formulários de anamnese integrativa bioenergética da Divine Energy (by Alessandra Nascimento), em três idiomas:

- `pt/` — Português
- `en/` — English
- `it/` — Italiano

A página inicial (`index.html`) permite escolher o idioma.

## Onde trocar o e-mail de destino

Em cada `*/index.html`, no início do `<script>`, altere `destinationEmail` (quem recebe as respostas) e `contactEmail` (e-mail exibido ao cliente).
O envio é feito pelo FormSubmit: no primeiro envio para um novo e-mail chega uma mensagem de ativação ("Activate Form") que precisa ser confirmada uma vez.
